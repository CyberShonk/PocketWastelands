Shonk's Pocket Wastelands

Tale of Two Wastelands on Android with GameNative and Droid Mod Loader.

This is the Android route for TTW. It is written around shared storage, GameNative container paths, DML deployment, handheld performance limits, and the extra plugin-file handoff New Vegas needs on Android.

Built for handhelds

Targets Android phones and handhelds first. Desktop TTW guides are useful, but mobile has different storage, driver, and testing problems.

DML first

Mod installation is written around Droid Mod Loader. PC tools are used only when they are still the cleanest way to generate or prepare files.

TTW is heavier

This setup is larger and more sensitive than a plain New Vegas setup. Test in smaller chunks and keep clean notes.

Before you start

Install New Vegas in shared storage

Do not put Fallout: New Vegas inside locked GameNative App Storage for this guide. DML needs practical access to the same game folder GameNative launches.

/storage/emulated/0/PcGames/Fallout New Vegas/

DML should deploy to the game Data folder, not the game root.

Game

English Fallout 3 and Fallout: New Vegas with all DLC. Ultimate Edition and GOTY-style installs are the clean target.

PC

A Windows PC is needed to generate TTW. Do not try to generate TTW directly on Android.

Android

An Android device running GameNative, plus enough free storage for the generated TTW archive and installed files.

Mod manager

Droid Mod Loader handles the Android-side mod import, priority, deployment, plugin discovery, and plugin-file writing.

Vanilla check

  1. Launch Fallout: New Vegas in GameNative with no mods.
  2. Start a new game and reach Doc Mitchell's house.
  3. Make a manual save.
  4. Quit the game completely.
  5. Relaunch and load that save.
