Mod List

Install the sections in order. Use the listed file unless the notes say otherwise. Extra file choices are written as normal notes for the mod they belong to.

Root tools are not normal DML Data mods

Root tools belong beside FalloutNV.exe. DML should deploy to Data. Keep those two locations separate.

Root tools

These files belong in the game root next to FalloutNV.exe.

Installer rule

If DML does not show the right installer choices yet, install the mod on PC with MO2, pick the options you need, zip the clean installed output, then install that zip in DML.

Check essentials

  1. Deploy in DML.
  2. Run plugin discovery.
  3. Enable TaleOfTwoWastelands.esm and YUPTTW.esm.
  4. Write plugin files.
  5. Copy plugins.txt and loadorder.txt into C:/users/xuser/AppData/Local/FalloutNV/.
  6. Launch the game.
  7. Start a new game and verify the TTW start happens.
